# CodSoft Java Programming Internship

This repository contains three Java projects completed as part of the **CodSoft Internship Program**. These tasks helped me strengthen my Java programming skills, logical thinking, and problem-solving abilities.

## Tasks Completed

### Task 1: Number Game
A Java-based number guessing game in which the user tries to guess a randomly generated number.

**Features:**
- Generates a random number.
- Takes user guesses as input.
- Provides hints if the guess is too high or too low.
- Tracks the number of attempts.
- Allows users to play multiple rounds.

### Task 2: Student Grade Calculator
A Java program that calculates a student's total marks, average percentage, and grade based on marks obtained in different subjects.

**Features:**
- Accepts marks for multiple subjects.
- Calculates total marks and average percentage.
- Assigns a grade based on the percentage.
- Displays the final result.

### Task 3: Currency Converter
A Java application that converts an amount from one currency to another.

**Features:**
- Accepts the amount to convert.
- Allows selection of source and target currencies.
- Calculates the converted amount using exchange rates.
- Displays the conversion result.

*Note: Conversion accuracy depends on whether the application uses fixed or live exchange rates.*

## How to Run

1. Clone this repository:

   ```bash

   ```

